# 모의투자 데스크

가상의 1,000만 원으로 국내·미국·중국·홍콩·일본 주식을 연습하는 모의투자 웹앱입니다.
**실제 주문은 절대 전송하지 않습니다** — 실제 시세만 읽어오고, 매매는 전부 가상입니다.

## 어떻게 동작하나

- **시세**: 서버가 Yahoo Finance에서 대신 받아옵니다 (브라우저는 CORS 때문에 직접 못 부름).
  API 키·가입 불필요. 지연 시세(시장별 15~20분)입니다.
- **잔고·보유종목·거래내역·관심종목**: 로그인 여부에 따라 저장 위치가 달라집니다.
  - 게스트(로그인 안 함): **그 사람의 브라우저에만** 저장됩니다. 방문자마다 각자 1,000만 원으로 시작해요.
  - 로그인함: **본인 계정(Supabase)에** 저장돼서 PC·휴대폰 어디서든 같은 잔고로 이어집니다.
  - 게스트로 하다가 로그인하면 그때까지의 기록이 계정으로 자동으로 옮겨집니다.
- **환율**: 해외 종목은 그 시점 환율로 원화 환산해서 예수금에서 차감합니다
  (토스증권 통합증거금과 비슷한 방식). 환율을 못 가져오면 주문이 막힙니다.

## 화면

- 종목명·현재가·등락률·요약 지표를 크게 키운 레이아웃입니다. 휴대폰에서는 관심종목이
  표 대신 카드 형태로 바뀌어 가로 스크롤 없이 한 화면에 들어옵니다.
- 오른쪽 위 **자동 / 밝게 / 어둡게** 버튼으로 화면 모드를 바꿉니다.
  선택은 브라우저에 저장되고(`mockTrading.theme.v1`), '자동'은 기기 설정을 따릅니다.
- 폰트는 Google Fonts의 `M PLUS Rounded 1c`(숫자·영문) + `Jua`(제목) + `Gothic A1`(본문)
  조합입니다. 인터넷이 끊기면 기기 기본 폰트로 대체됩니다.

## 주요 기능

- **종목 검색**: 이름 일부만 입력해도 찾아줍니다 ("삼성" → 삼성전자). 코드로 직접 추가도 가능합니다.
- **기간별 차트**: 주문창에서 1일 / 1주 / 1개월 / 1년 흐름을 볼 수 있습니다.
- **수익률 랭킹**: 로그인 후 닉네임을 정하면 전체 참가자 순위에 오릅니다.
  켜려면 [RANKING-SETUP.md](./RANKING-SETUP.md) 의 SQL을 실행해야 합니다.
- **관심종목 접기**: 기본 5개만 보이고 나머지는 "전체 보기"로 펼칩니다.

## 로그인 (구글)

기본 상태에서는 **로그인 기능이 꺼져 있고**, 사이트는 게스트 전용으로 잘 동작합니다.
켜려면 [LOGIN-SETUP.md](./LOGIN-SETUP.md) 를 따라 Supabase 프로젝트를 만들고
`config.js` 에 값 두 개를 채우면 됩니다. 그 순간부터 헤더에 "구글로 로그인" 버튼이 나타납니다.

- 로그인해도 **게스트로 계속 쓸 수 있습니다** (로그인 강제 아님)
- 계정 데이터는 `portfolios` 테이블에 사용자당 한 줄(JSON)로 저장됩니다
- 보안 규칙(RLS)으로 각자 자기 줄만 읽고 쓸 수 있습니다

## 내 컴퓨터에서 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

## Vercel 배포

이 저장소를 Vercel에 연결하면 그대로 배포됩니다. 설정할 환경변수도, 연결할 데이터베이스도 없습니다.

- `api/` 폴더의 파일들이 서버리스 함수가 됩니다 (`/api/quotes`, `/api/history`, `/api/lookup`, `/api/markets`)
- 루트의 `index.html` / `app.js` / `store.js` / `styles.css` 가 정적 파일로 서빙됩니다
- `server/dev.js` 는 로컬 개발용이라 배포에서는 실행되지 않습니다

## 구조

```
index.html, app.js, store.js, auth.js, config.js, styles.css   프론트엔드 (정적 파일)
  store.js    잔고·보유종목·거래내역·관심종목 보관 + 매매 계산 (브라우저 또는 계정에 저장)
  auth.js     구글 로그인 + 계정 데이터 읽기/쓰기 (Supabase)
  config.js   Supabase 주소·공개키 (비어 있으면 로그인 기능 꺼짐)
  app.js      화면 렌더링 + 서버에서 시세 받아오기
api/
  quotes.js   시세 + 환율
  history.js  스파크라인용 최근 흐름 (5분봉)
  chart.js    기간별 차트 (1일/1주/1개월/1년)
  search.js   종목 이름으로 검색
  lookup.js   종목코드로 종목 찾기 (직접 추가할 때)
  markets.js  지원 시장 목록
lib/
  yahoo.js    Yahoo Finance 호출 + 짧은 캐시
  markets.js  시장별 심볼 규칙·통화·표시 형식
  handlers.js API 로직 본체 (서버리스와 로컬 개발 서버가 공유)
server/dev.js 로컬 개발 서버 (배포에는 미포함)
```

## 알아둘 점

- 지연 시세라 실시간 판단 근거로는 쓸 수 없습니다. 각 종목 옆에 그 가격이 언제 것인지
  표시됩니다 (`장중 14:23` / `15:30 종가` / `9/4 종가`).
- 갱신 주기: 장이 열려 있으면 5초, 다 닫혀 있으면 60초. 다른 탭을 보고 있는 동안에는
  아예 갱신하지 않고, 탭으로 돌아오면 즉시 한 번 받아옵니다 (서버 호출량 절약).
  더 짧게 줄여도 원본 시세 자체가 지연 시세라 값은 같습니다.
- 해외 시장은 현지 장시간에만 움직입니다. 마감 후에는 종가가 유지됩니다.
- 게스트일 때는 브라우저 데이터를 지우면 잔고도 초기화되고, PC와 휴대폰이 각각 별도 잔고를 가집니다.
  로그인하면 그런 문제가 없어집니다.
- 수수료·세금·호가 잔량은 반영하지 않은 단순화된 모의매매이며, 주문은 전량 즉시 체결됩니다.
