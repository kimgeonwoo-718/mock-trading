# 모의투자 데스크

가상의 1,000만 원으로 국내·미국·중국·홍콩·일본 주식을 연습하는 모의투자 웹앱입니다.
**실제 주문은 절대 전송하지 않습니다** — 실제 시세만 읽어오고, 매매는 전부 가상입니다.

## 어떻게 동작하나

- **시세**: 서버가 Yahoo Finance에서 대신 받아옵니다 (브라우저는 CORS 때문에 직접 못 부름).
  API 키·가입 불필요. 지연 시세(시장별 15~20분)입니다.
- **잔고·보유종목·거래내역·관심종목**: **접속한 사람의 브라우저에만** 저장됩니다.
  방문자마다 각자 1,000만 원으로 시작하고, 서로의 데이터가 섞이지 않습니다.
  서버는 아무것도 저장하지 않습니다.
- **환율**: 해외 종목은 그 시점 환율로 원화 환산해서 예수금에서 차감합니다
  (토스증권 통합증거금과 비슷한 방식). 환율을 못 가져오면 주문이 막힙니다.

## 화면

- 종목명·현재가·등락률·요약 지표를 크게 키운 레이아웃입니다. 휴대폰에서는 관심종목이
  표 대신 카드 형태로 바뀌어 가로 스크롤 없이 한 화면에 들어옵니다.
- 오른쪽 위 **자동 / 밝게 / 어둡게** 버튼으로 화면 모드를 바꿉니다.
  선택은 브라우저에 저장되고(`mockTrading.theme.v1`), '자동'은 기기 설정을 따릅니다.
- 폰트는 Google Fonts의 `M PLUS Rounded 1c`(숫자·영문) + `Jua`(제목) + `Gothic A1`(본문)
  조합입니다. 인터넷이 끊기면 기기 기본 폰트로 대체됩니다.

## 지원 시장

| 시장 | 통화 | 종목코드 | 예시 |
|---|---|---|---|
| 국내 (코스피/코스닥) | KRW | 숫자 6자리 | 삼성전자 `005930` |
| 미국 | USD | 영문 티커 | 애플 `AAPL` |
| 홍콩 | HKD | 숫자 4자리 | 텐센트 `0700` |
| 중국 상해 | CNY | 숫자 6자리 | 귀주모태 `600519` |
| 중국 심천 | CNY | 숫자 6자리 | 오량액 `000858` |
| 일본 | JPY | 숫자 4자리 | 도요타 `7203` |

## 내 컴퓨터에서 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

## Vercel 배포

이 저장소를 Vercel에 연결하면 그대로 배포됩니다. 설정할 환경변수도, 연결할 데이터베이스도 없습니다.

- `api/` 폴더의 파일들이 서버리스 함수가 됩니다 (`/api/quotes`, `/api/history`, `/api/lookup`, `/api/markets`)
- 루트의 `index.html` / `app.js` / `store.js` / `styles.css` 가 정적 파일로 서빙됩니다
- `server/dev.js` 는 로컬 개발용이라 배포에서는 실행되지 않습니다

## 구조

```
index.html, app.js, store.js, styles.css   프론트엔드 (정적 파일)
  store.js    잔고·보유종목·거래내역·관심종목을 브라우저에 저장하고 매매를 계산
  app.js      화면 렌더링 + 서버에서 시세 받아오기
api/
  quotes.js   시세 + 환율
  history.js  스파크라인용 최근 흐름 (5분봉)
  lookup.js   종목코드로 종목 찾기 (추가할 때)
  markets.js  지원 시장 목록
lib/
  yahoo.js    Yahoo Finance 호출 + 짧은 캐시
  markets.js  시장별 심볼 규칙·통화·표시 형식
  handlers.js API 로직 본체 (서버리스와 로컬 개발 서버가 공유)
server/dev.js 로컬 개발 서버 (배포에는 미포함)
```

## 알아둘 점

- 지연 시세라 실시간 판단 근거로는 쓸 수 없습니다. 각 종목 옆에 그 가격이 언제 것인지
  표시됩니다 (`장중 14:23` / `15:30 종가` / `9/4 종가`).
- 해외 시장은 현지 장시간에만 움직입니다. 마감 후에는 종가가 유지됩니다.
- 브라우저 데이터를 지우면 잔고도 초기화됩니다. PC와 휴대폰은 각각 별도 잔고를 가집니다.
- 수수료·세금·호가 잔량은 반영하지 않은 단순화된 모의매매이며, 주문은 전량 즉시 체결됩니다.

## 다음에 할 만한 것

- **로그인 붙이기**: 계정별로 잔고를 나누려면 로그인 + 데이터베이스가 필요합니다.
  지금은 브라우저 저장이라 기기를 옮기면 잔고가 따라오지 않습니다.
- **수수료·세금 반영**: 실제 매매에 가깝게 만들려면 매도 시 거래세, 매수/매도 수수료를 넣으면 됩니다.
